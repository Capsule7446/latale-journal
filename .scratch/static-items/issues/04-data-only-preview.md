Status: ready-for-agent

## 交付

落实 2026-11-09 用户决定：页面所有游戏资料只来自 data 固定解析，取消虚构演示和 AI 添加的描述；固定 UI 标签与方案序号可保留。规则以 [开发约定](../../../docs/development.md#展示资料来源) 为准。

前端维护 `contracts/items-v1/`，资料仓库 `static-items/03-static-export` 消费冻结身份并导出。首次只接已核验的完整公开编号、名称、原说明、分类路径和状态；未证初始形态、属性、图标和途径不补写。

## 验收

- [ ] 旧虚构 JSON、图标、生成脚本、正常/错误/查询参数回退均移除。
- [ ] 静态读取 current、不可变 manifest 与全部公开道具；校验格式、契约身份、大小与 SHA-256，失败不切入不完整版本。
- [ ] 名称与说明逐字段来自固定产物；缺说明、未知分类和未接入能力诚实显示，旧筛选 URL 不产生假结果。
- [ ] 真实测试包亦由 data 固定生成；全量计数、编号 84905009、缺失分类、320px、桌面、失败重试与无业务 API 验收通过。
- [ ] README、当前预览记录和任务记录真实命令、资料身份及历史 SQLite 后半段边界；不声称 PWA、原始资源导入或云端已完成。
