# 静态道具查询

Status: ready-for-agent

日期：2026-11-08。Epic：`static-items`。本文件迁入既有道具需求，并采用本仓库已确认的纯前端架构；**需求已确认不等于静态实现已完成**。应用、正式业务契约、静态资料包、PWA 与 Cloudflare 部署均未随本次文档迁移完成。

## 问题与交付目标

旧预览的道具查询依赖本机查询服务，其他部分仍使用样本。新版需要从独立发布的静态资料完成查询、详情与跳转，兼容资料更新不重建前端。保留已确认界面、业务含义与取消项，不把旧服务或旧 demo 的验收结论转记为新版通过。

完整交付路径：只读真实资料 → 固定程序核验 → 冻结前端契约 → 版本化静态包 → 浏览器查询与详情 → Cloudflare PWA。每次验收注明范围；只读 SQLite 的后半段验证不能证明已从客户端资源重建。

## 用户需要完成的操作

| 操作 | 预期结果 |
| --- | --- |
| 按名称或编号找道具 | 查询完整公开范围，保留同名不同编号，计数和分页准确 |
| 组合分类、搜索范围与条件 | 条件有明确含义，未知值不会被当成零、否或不限 |
| 只看初始形态，再查强化版本 | 普通版、觉醒版各保留自身初始形态，详情切换到真实版本 |
| 看品类属性、获取方式与用途 | 保留单位、关系方向和缺失状态，不推算玩家实例结果 |
| 追查材料、来源或关联资料后返回 | 精确打开目标，恢复原搜索、详情和浏览位置 |
| 安装并离线阅读已访问资料 | 已缓存内容可读；未缓存内容说明需要联网，不伪装成无结果 |
| 获取新资料 | 同一应用构建可读取两份兼容资料包，失败保留可用旧版 |

## 查询规则

### 名称、编号与文字范围

基础查询始终包含道具名称和精确道具编号。名称按字面包含匹配，去首尾空白；沿用 NFKC 和英文大小写归一，不加入拼音、纠错或模糊猜测。纯数字只精确匹配道具编号，不匹配编号前缀，也不扩展为套装编号。无匹配返回空结果，不回退到相似对象。

三个附加范围为“道具说明”“Buff名称与说明”“套装名称”，分别勾选，首次进入且没有恢复状态时均关闭。名称与已勾选文字范围取并集，按道具编号去重，再与分类及其他条件取交集。套装范围只通过明确的套装成员关系取道具，不按道具名称或升级连通关系扩展成员。Buff 仅搜索游戏原名称与原说明，不把属性或词条表追加为文字索引。

完整同名记录优先，其余包含命中按道具编号升序；同级仍按编号升序。无关键词按编号升序。同名不同编号不能覆盖。文字只命中附加范围的记录也遵守相同优先级。

### 分类

五大类为装备、消耗、其他、任务、宠物。采用可展开树状多选；分类路径层数不限、各分支深度可不同。分支取并集，与其他条件取交集；父节点覆盖已识别后代。路径身份来自稳定键及父关系，不使用中文名称作为唯一键。

没有“未分类”入口。未选任何分类时，缺分类道具仍可参与搜索；选择任意分类，包括父类或全部五大类，都排除分类未识别记录。清空分类后恢复资格并保留关键词。无需更深分类与分类尚未解析不同，不补造层级。

展开、收起不改变选择、结果或页码；收起保留后代选择。移除一个分支不清除其他分支，分类变化回第一页；返回恢复选择及展开状态。

### 使用限制与道具特性

| 条件 | 规则 |
| --- | --- |
| 职业条件 | 默认不限；按明确职业成员引用匹配。控件不能宣称完整的“可装备资格”，未解析的组间关系不补为 AND/OR |
| 普通等级、超越Ⅰ、超越Ⅱ | 三种制度各自设可空最低/最高值，含边界，单端为单侧范围。普通及Ⅰ为整数，Ⅱ按已证显示值精确比较、最多两位小数；不互换制度 |
| 无效等级范围 | 上下界倒置、普通/Ⅰ小数、Ⅱ超过两位小数时提示修正，保留原条件，不静默交换、取整或截断 |
| 交易、存仓、破坏、拍卖 | 四项独立“不限／可以／不可以”，默认不限。未知仅在不限时保留，不归到任一布尔值 |
| 缺少条件 | 没有该等级制度的明确数值时不命中该等级范围；无职业条件不自动表示适用所有职业。无配置、未知和明确的零分别保存 |

所有选定条件同时满足；单项清除保留其他条件。只提供有证据且适用的字段，不推算封印等操作后的特性。

### 初始形态与强化版本（Q41～Q43 最新决定）

“只看初始状态”默认开启，可关闭查看各独立阶段。普通版与觉醒版分别保留自身尚未强化的初始形态，不把整条路线压成最早普通版。

开启时，保留的初始形态**自身必须满足**关键词、分类、职业、等级、特性等全部条件。仅强化版满足而初始版不满足时，排除该装备；不替换为不匹配的初始编号，也不回退展示强化版。过滤完成后再计算总数、排序与分页。精确编号或带明确强化后缀的查询保留具体阶段，不应用该初始形态过滤；分类等其余条件仍生效。

升级关系须由真实主输入与产物编号证明。普通／觉醒分段、初始形态和安全系列归属仍需全量取证；不能用名称、后缀、编号相近或整个升级连通分量猜出关系。未证明的记录保留可追查的数据状态，不冒充已完成全库初始形态过滤；默认开关的完整交付仍受此门槛约束。

详情在原属性区内切换真实强化版本，不新增强化主标签，不生成不存在的阶段。标题、编号、图标、分类、限制、属性、词条、觉醒、套装、效果、特性、获取和用途都绑定所选编号；缺字段不继承其他版本。保持当前详情分区和原列表条件。强化阶段、装备等级要求、武器觉醒词条阶段是不同概念。

### 分页与输入

对完整公开范围先执行全部过滤，再稳定排序、分页。默认每页 10 条，可选 10/20/40；总数是最终命中数。搜索、分类、附加范围或其他条件变化回第一页；修改每页条数保留原页首记录所在的新页。首末页无效按钮禁用，跳页校验正整数与范围。中文输入法合成结束后查询，普通输入停顿 220ms 后处理；旧请求不得覆盖最新结果。

## 详情与关联

### 已确认布局

列表只显示图标、原名称及阶段、完整分类路径、编号；其他属性在详情。沿用 2026-10-22 已确认版式，不重新选择整套视觉或固定主标签。

| 品类 | 固定主标签 |
| --- | --- |
| 装备 | 属性／套装（有数据时）／获取方式／用途 |
| 消耗 | 使用效果／获取方式 |
| 其他 | 道具说明／材料用途／获取方式 |
| 任务 | 道具说明／关联任务／材料用途／获取方式 |
| 宠物 | 属性／获取方式／配合的阵容 |

基础区保留名称和完整分类路径。内容宽度至少 1024px 时列表与详情分栏，更窄时打开全屏详情；全页自然滚动，最大内容宽度 1600px。保持浅／深／系统外观、标准／紧凑密度、已证游戏名称色和至少 44px 触控目标；320px 页面不横向溢出。窄屏路径可换行，不静默删中间节点。

### 品类内容

| 内容 | 必须保留的含义 |
| --- | --- |
| 装备限制与成长 | 职业、三种等级、固定属性、四项特性分开。耐久、强化上限、镶嵌／强化石、封印按各字段证据展示；封印配置基数不是玩家剩余次数，已收录末端不等于最高强化上限 |
| 普通词条 | 武器列真实关联的候选名称，不分页；同名合并展示时保留全部来源身份。战斗钥匙、徽章、宝石保留各配置的最小／最大值、单位与 80% 参考值；同名不同来源、等级、条件或范围不混成极值区间。只能证明初始候选池时明确标注，不能冒充洗练／镶嵌后的最终上下限；最终范围未证状态保留 |
| 80% 参考值 | 精确十进制计算 `(最大值 - 最小值) * 0.8 + 最小值`，不取整，不表示概率、分位数或可生成的实例值。零、负数及固定范围正常保留；缺定义、缺单位或倒置范围不补值、不交换端点，参考值显示 `-` 并说明原因 |
| 武器觉醒词条 | 按实际配置阶段分组，默认全部展开，完整候选不分页，阶段内沿原顺序。保留属性与技能等级及其单位；同名不同单位／范围／来源分别显示。不固定为四阶段、不增加觉醒 80% 值或候选概率 |
| 套装 | 名称、编号、最低生效件数、每档与满套效果、成员及真实阶段。数值保留属性身份、值、单位、原模板及显示文本；特殊效果保留原文。不从成员条数推门槛，不累计各档为总加成，档位全部直接显示 |
| 称号书 | 对应称号与该书配置解锁成功率、称号属性及特殊效果、书自身使用说明分别显示。成功率按书及其明确授予配置，不继承同名书；缺称号目标时不造跳转 |
| 消耗与 Buff | 道具使用说明、关联 Buff 名称、Buff 原说明分区；保留原换行、标点、数字、时间和条件。区分自身／目标效果及普通／PVP配置。单条／全部复制仅真实 Buff 名称，每行一名；缺名、缺说明和断链分别处理 |
| 宠物 | 自身说明与阵容加成分开；按加成方案身份去重，属性表与特效原文各自保留。不展开六宠组合；缺原生方案名时可用“加成方案＋编号”。不累计多个方案，不把参与配置解释为单宠触发 |

数量、费用、百分比及属性保留明确单位，未知不包装为零。数值与候选表示客户端定义，不表示玩家已拥有或同时生效。词条缺口按既有决定延期处理，已证内容先展示；延期不等于解析完成，也不豁免其他字段的语义核验。

### 获取方式与用途

获取当前道具与当前道具的用途分开；各配方独立展示主输入、材料、产物、数量、已知费用和条件，不用两方向材料对照表，不合计整条升级路线。

| 关系组 | 要求 |
| --- | --- |
| 制作、加工与升级 | 保留生活制作、其他／旧版／特殊配置各自来源与状态；升级入向与后续升级分别展示。材料反查保留完整配方，不混淆配方身份与道具身份 |
| 分解双向关系 | 用途显示本件产出，获取显示哪些原道具分解能得到本件；保留方案／条件／槽、逐产物数量、费用及概率状态。已证百分比按未取整值降序后分页；未知显示 `-`，不当 0、不归一化、不相加重复槽概率 |
| 掉落、购买、兑换 | 怪物、地图／副本及难度只按确切关系显示；出现地点不保证掉落。NPC 名称与各自地点、菜单正确配对；未知售价／币种不从原价或倍率猜。商城配置不表示当前在售 |
| 任务与奖励、开包 | 任务接取所得、完成奖励、提交消耗是不同角色。系统／活动奖励、NPC奖励池及礼包保留配置与候选规则，候选不冒称全部必得；开包来源与开包产出分别反查 |
| 适用对象 | 保留已证镶嵌、洗练、强化、封印等操作及目标；材料出现于规则不等于已得到全部精确适用道具，不能把属性结果编号当道具编号 |

分解逐材料获得概率与总操作成功率不同；没有可靠分母与抽取语义时不得加百分号，也不要求各材料概率之和为 100%。数量、费用和条件属于同一操作／方案，获取方向数量是当前道具的产出数。缺失显示 ASCII `-`，真实费用 0 保留。没有收录来源不等于无法获得，没有用途记录不等于无法使用。

获取区沿用制作／升级／其他来源分组，用途按真实操作分组。关系列表默认 5 条，可选 5/10/20；宠物加成方案默认 3 条，可选 3/5/10；词条不分页。详情分组和分页不改变道具列表查询或总数。

### 途径折叠与多方案（2026-11-09 用户确认）

材料用途／用途及获取方式中的制作、兑换、购买、分解、升级等途径，首次进入时默认收起。外层先显示可读的途径描述，点击或用键盘展开后才显示具体材料、产物、数量、费用和条件；不将一份完整配方直接铺在外层。各组可独立展开／收起，已有恢复状态时按返回规则恢复。

| 途径 | 外层描述 |
| --- | --- |
| 兑换 | `[兑换]NPC姓名`，例如 `[兑换]XXXXXX` |
| 生活技能 | `[生活技能／成品类别名称][Lv等级]制造分类路径`，用户示例为 `[吉恩蒂亚成品][Lv1]成品制造 > 拳套`；标签和路径按真实资料输出，示例不代表已证解析字段 |
| 购买 | `[购买][NPC姓名]` |
| 分解 | `[分解][原材料名称]`，原材料指分解输入道具 |
| 升级 | `[升级][原主材料名称]`，原主材料指作为升级主输入的道具，不取任一辅助材料代替 |

同一途径描述下有多个方案时，外层只展示一条，展开后分别显示全部方案。例如同一 NPC 用不同材料兑换同一道具，应为一个 `[兑换]NPC姓名` 入口，内含多份材料清单。它是展示分组，不是合并配方：不同方案的身份、材料／产物、数量、费用、地点和条件不得覆盖、相加或拼接成一个方案。

分组限制在当前道具与当前获取／用途方向内；兑换／购买按各自途径类型与真实 NPC 身份，生活技能按真实类别／等级／路径身份，分解／升级按各自途径类型与真实主输入身份。仅中文名字相同但身份不同不混组；身份未证时保留独立记录与缺失说明，不靠标题猜关系。相同 NPC 的地点与办理条件仍保留在对应内部方案。外层可标注方案数，关系列表在分组完成后分页，不能把同组方案切成多个重复外层入口。

展开状态按道具、方向和稳定途径键保存；追查内部材料后返回，恢复原途径展开状态、关系页码、滚动和焦点。此折叠要求不改变武器觉醒候选默认完整展开、不分页等其他已确认规则。

### 精确跳转与恢复

所有关系按实体类型＋业务编号定位；名称只显示，不重新搜索名称代替跳转。道具、任务、套装、称号、配方、怪物、地图和副本各自核验真实关系。目标存在但所属页面尚未迁入时保留必要摘要及明确状态，不能把旧站外链当新页完成。NPC仅内嵌姓名、地点和办理信息。

返回恢复关键词、附加范围、分类选择与展开、全部筛选、页码／条数、原道具与所选版本、详情分区、关系页码、滚动和焦点；连续追查逐层返回。页内返回与浏览器前进后退一致。URL 保存可重放查询与选择，历史状态保存滚动／焦点。旧升级链接的入向配方和后续用途语义分别适配。

关系存在但目标缺失时保留文字／占位并禁用链接，不跳同名对象。加载、请求失败、无匹配、目标缺失、未缓存、版本中移除分别处理；重试保留状态，图片失败不隐藏文字，复制失败不显示成功。

## 静态契约、PWA 与实现门槛

浏览器仅读取静态 JSON 和图片，开发服务只托管资源并提供热更新。契约由本仓库维护，生产者锁定版本、来源提交与 SHA-256；这份文字规格不是正式 Schema。搜索索引必须覆盖已声明的完整公开范围，不只过滤当前页面或已缓存详情。

应用版本、格式版本与资料版本独立；一次读取锁定同一资料版本。资料路径不可变，新版本校验准备完成后整体切换，失败保留旧版；不能混用不同版本的详情、索引和关联。兼容资料更新不修改或重建应用。

首版 PWA 支持手机与电脑安装，页面及已访问资料可离线；未缓存资料提示联网。离线搜索明确可用范围，缓存子集不能冒称全库。安装、独立启动、更新、缓存失效／容量不足的恢复需要生产构建验收。Cloudflare 产品选择、容量与部署参数仍按实现证据确定，本次未开通或部署。
