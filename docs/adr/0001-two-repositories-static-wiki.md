# 前端与资料生产分成两个独立仓库

2026-11-08，用户要求在两个新仓库中落实新版 Wiki 定义：`latale-journal` 负责 Cloudflare 上的纯前端 PWA 及其 JSON 契约，`latale-wiki-data` 负责从客户端资源固定解析、校验、打包并独立发布静态资料。拆分使应用与资料能够分别开发和发布，代价是必须明确维护契约版本、兼容性和跨仓库验收；本仓库维护契约源，生产者锁定其不可变内容身份。

线上不依赖动态查询服务，兼容资料更新不重发应用；首版页面和已访问资料可离线，未缓存内容需要联网。资料生产不能以 AI 为运行依赖，AI 辅助开发的规则也须落成固定代码并验证。具体规范见 [开发约定](../development.md)与 [数据契约协作](../data-contract.md)，本决定不表示应用或云端部署已完成。
